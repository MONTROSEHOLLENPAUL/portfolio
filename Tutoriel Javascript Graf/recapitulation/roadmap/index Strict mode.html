Strict mode

Le mode strict de JavaScript est un moyen d’opter pour une variante restreinte de JavaScript, ce qui permet implicitement de se désinscrire du « mode bâclé ». Le mode strict n’est pas seulement un sous-ensemble : il a intentionnellement une sémantique différente de celle du code normal. Les navigateurs qui ne prennent pas en charge le mode strict exécuteront du code en mode strict avec un comportement différent de celui des navigateurs qui le font, alors ne comptez pas sur le mode strict sans tester les fonctionnalités pour la prise en charge des aspects pertinents du mode strict. Le code en mode strict et le code en mode non strict peuvent coexister afin que les scripts puissent passer en mode strict de manière incrémentielle.
Le mode strict apporte plusieurs modifications à la sémantique JavaScript normale :
Élimine certaines erreurs silencieuses JavaScript en les remplaçant par des erreurs de levée.
Corrige les erreurs qui rendent difficile l’optimisation des moteurs JavaScript : le code en mode strict peut parfois s’exécuter plus rapidement qu’un code identique qui n’est pas en mode strict.
Interdit certaines syntaxes susceptibles d’être définies dans les futures versions d’ECMAScript.
