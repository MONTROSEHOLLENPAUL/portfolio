Gestion des exceptions

En JavaScript, toutes les exceptions sont simplement des objets. Bien que la majorité des exceptions soient des implémentations de la classe globale Error, n’importe quel ancien objet peut être levé. En gardant cela à l’esprit, il existe deux façons de lever une exception : directement via un objet Error et via un objet personnalisé. (extrait de Rollbar)

Instruction Throw

L’instruction throw lève une exception définie par l’utilisateur. L’exécution de la fonction courante s’arrêtera (les instructions après throw ne seront pas exécutées) et le contrôle sera passé au premier bloc catch de la pile des appels. S’il n’existe pas de bloc catch parmi les fonctions appelantes, le programme s’arrête.

Ce sont des façons de gérer les erreurs dans votre code JavaScript. À l’intérieur du bloc de code try, nous avons le code à exécuter, à l’intérieur du bloc catch nous gérons les erreurs, et à l’intérieur du bloc finally nous avons du code qui s’exécute après l’exécution des blocs de code précédents, quel que soit le résultat.
