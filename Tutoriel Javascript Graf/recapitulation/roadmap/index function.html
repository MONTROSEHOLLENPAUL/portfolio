functions

Des fonctions existent pour que nous puissions réutiliser le code. Ce sont des blocs de code qui s’exécutent chaque fois qu’ils sont appelés. Chaque fonction est généralement écrite pour effectuer une tâche particulière, comme une fonction d’addition utilisée pour trouver la somme de deux nombres ou plus. Lorsque des nombres doivent être ajoutés n’importe où dans votre code, la fonction d’addition peut être appelée autant de fois que nécessaire.

Paramètres de fonction

Le paramètre est le nom donné à la variable déclarée à l’intérieur de la définition d’une fonction. Il existe deux types de syntaxe spéciaux : les paramètres par défaut et les paramètres rest.

Paramètres de repos(rest params)

La syntaxe du paramètre rest permet à une fonction d’accepter un nombre indéfini d’arguments sous forme de tableau, ce qui permet de représenter des fonctions variadiques en JavaScript.
syntax function f(a, b, ...theArgs) { // … }

Paramètres par défaut(default params)

Les paramètres de fonction par défaut permettent d’initialiser les paramètres nommés avec des valeurs par défaut si aucune valeur n’est transmise.undefined
syntax function fnName(param1 = defaultValue1, /* …, */ paramN = defaultValueN) { // … }

Fonctions fléchées(arrow functions)

La fonction fléchée est une nouvelle façon de créer des fonctions avec l’opérateur '=>' avec une syntaxe plus courte.
syntaxe
() => expression
param => expression
(param) => expression
(param1, paramN) => expression
() => { statements }
param => { statements }
(param1, paramN) => { statements }

L’IIFE (Immediate Invoked Function Expression)

L’expression de fonction appelée immédiatement est une fonction qui est exécutée immédiatement après sa création.
(function () { // … })();
(() => { // … })();
(async () => { // … })();

Cas d’utilisation

Éviter de polluer l’espace de nommage global Parce que notre application peut inclure de nombreuses fonctions et variables globales à partir de différents fichiers sources, il est important pour limiter le nombre de variables globales. Si nous avons un code d’initiation que nous n’avons pas besoin d’utiliser encore une fois, nous pourrions utiliser le modèle IIFE. Comme nous ne réutiliserons pas le code à nouveau, il est préférable d’utiliser IIFE dans ce cas plutôt que de à l’aide d’une déclaration de fonction ou d’une expression de fonction

Argument objet

L’objet arguments est un objet de type tableau accessible à l’intérieur des fonctions qui contient les valeurs des arguments passés à cette fonction, disponible dans toutes les fonctions autres que les flèches. Vous pouvez faire référence aux arguments d’une fonction à l’intérieur de cette fonction à l’aide de son objet arguments. Il a des entrées pour chaque argument avec lequel la fonction a été appelée, avec l’index de la première entrée à 0. Mais, dans le code moderne, les paramètres rest doivent être préférés.

Étendue et pile de fonctions

Portée

Un espace ou un environnement dans lequel une variable ou une fonction particulière peut être accédée ou utilisée. L’accessibilité de cette variable ou fonction dépend de l’endroit où elle est définie.
Étendue globale : étendue par défaut pour tout le code exécuté en mode script.
Étendue du module : étendue du code s’exécutant en mode module.
Étendue de la fonction : étendue créée à l’aide d’une fonction.
Portée du bloc : portée créée à l’aide d’une paire d’accolades (un bloc).

Pile de fonctions (pile d’appels)

La pile de fonctions est la façon dont l’interpréteur garde une trace de sa place dans un script qui appelle plusieurs fonctions, comme la fonction en cours d’exécution et les fonctions de cette fonction qui sont appelées.

Récursion

L’un des concepts de fonctions les plus puissants et les plus élégants, la récursivité se produit lorsqu’une fonction s’invoque elle-même. Une telle fonction est appelée fonction récursive. Au fur et à mesure que la récursivité se produit, le code sous-jacent de la fonction récursive est exécuté encore et encore jusqu’à ce qu’une condition de fin, appelée cas de base, soit remplie. En plongeant dans le monde des algorithmes, vous rencontrerez la récursivité dans de nombreux cas.

Portée lexicale

Avant de pouvoir se faire une idée des fermetures en JavaScript, il est important de se familiariser avec le terme « environnement lexical ». Fermetures(closure)

Les fermetures de fonctions sont l’un des concepts les plus puissants, mais aussi les plus mal compris, de JavaScript qui sont en fait très simples à comprendre. Une fermeture fait référence à une fonction ainsi qu’à son environnement lexical. C’est essentiellement ce qui nous permet de retourner une fonction , à partir d’une autre fonction , qui se souvient des variables locales définies dans , même après des sorties. L’idée de fermetures est employée dans presque tous les autres programmes JavaScript, il est donc primordial pour un développeur JavaScript de le connaître très bien.ABBB

Fonctions intégrées

Une méthode JavaScript est une propriété contenant une définition de fonction. En d’autres termes, lorsque les données stockées sur un objet sont une fonction, nous appelons cela une méthode. Pour différencier les propriétés des méthodes, nous pouvons y penser de cette façon : une propriété est ce qu’un objet possède, tandis qu’une méthode est ce qu’un objet fait. Étant donné que les méthodes JavaScript sont des actions qui peuvent être effectuées sur des objets, nous devons d’abord avoir des objets pour commencer. Il y a plusieurs objets intégrés à JavaScript que nous pouvons utiliser.
