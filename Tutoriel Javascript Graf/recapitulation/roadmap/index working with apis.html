Utilisation des API

Lorsque vous travaillez avec des API distantes, vous avez besoin d’un moyen d’interagir avec ces API. Le JavaScript moderne fournit deux méthodes natives pour envoyer des requêtes HTTP à des serveurs distants, et .XMLHttpRequestFetch

XMLHttpRequest

XMLHttpRequest (XHR) est un objet de navigateur intégré qui peut être utilisé pour interagir avec le serveur. XHR vous permet de mettre à jour les données sans avoir à recharger une page web. Malgré le mot XML dans son nom, XHR n’est pas seulement utilisé pour récupérer des données au format XML, nous pouvons l’utiliser avec n’importe quel type de données, comme JSON, fichier(s), et bien plus encore.

Chercher(fetch)

La méthode fetch() en JavaScript est utilisée pour demander au serveur et charger les informations sur les pages Web. La demande peut provenir de n’importe quelle API qui renvoie les données au format JSON ou XML. Cette méthode renvoie une promesse.
