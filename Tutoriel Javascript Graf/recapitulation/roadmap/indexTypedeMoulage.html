Type de Moulage

La conversion de type (ou typecasting) désigne le transfert de données d’un type de données à un autre. La conversion implicite se produit lorsque le compilateur (pour les langages compilés) ou le runtime (pour les langages de script comme JavaScript) convertit automatiquement les types de données. Le code source peut également exiger explicitement qu’une conversion ait lieu.

Moulage de type explicite

La conversion de type consiste à transférer des données d’un type de données à un autre en spécifiant explicitement le type vers lequel convertir les données données. La conversion de type explicite est normalement effectuée pour rendre les données compatibles avec d’autres variables. Des exemples de méthodes de conversion de caractères sont , , .parseInt()parseFloat()toString()

ParseInt ()

Il convertit une valeur donnée en un nombre entier, s’il n’est pas possible de convertir la valeur NaN de retour.

ParseFloat ()

La fonction ParseFloat () renvoie un nombre à virgule flottante qui analyse une chaîne. Cette fonction détermine si le premier caractère d’une chaîne particulière est un nombre.

Conversion de type implicite

La conversion de type implicite se produit lorsque le compilateur ou le runtime convertit automatiquement les types de données. JavaScript est un langage à typage lâche et la plupart du temps, les opérateurs convertissent automatiquement une valeur en le bon type.

La coercition implicite de Javascript fait simplement référence à Javascript qui tente de contraindre un type de valeur inattendu au type attendu. Ainsi, vous pouvez passer une chaîne là où il attend un nombre, un objet où il attend une chaîne, etc., et il essaiera de le convertir en le bon type. Il s’agit d’une fonctionnalité Javascript qu’il vaut mieux éviter.

Type Conversion/Coercition

La coercition de type est la conversion automatique ou implicite de valeurs d’un type de données à un autre (par exemple, des chaînes en nombres). La conversion de type est similaire à la coercition de type, car elle convertit les valeurs d’un type de données à un autre, avec une différence clé : la coercition de type est implicite. En revanche, la conversion de type peut être implicite ou explicite.
